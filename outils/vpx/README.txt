FANNY PINBALL - PETANQUE WORLD TOUR (Arducible 2026) v1.0
=========================================================
Original table for Visual Pinball X / Table originale pour Visual Pinball X

#arducible, the DIY petanque game
Source: https://github.com/guiraudjb/fanny-pinball (outils/vpx)


ENGLISH
-------
Requirements
  - Visual Pinball X 10.8 or later (tested on VPX 10.8.0 standalone, Linux / Batocera, desktop view).
  - NO ROM, no VPinMAME, no controller.vbs: original game, all rules are in the table script.
  - Sounds, music, playfield art and the animated desktop background are embedded in the .vpx.
  - No .directb2s yet: the desktop view shows the backglass art and the dot-matrix display on the right.

Install
  Copy "Fanny Pinball (Arducible 2026) v1.0.vpx" into your tables folder and launch it.

Keys (standard VPX keys)
  Left / Right Shift : flippers        Enter      : plunger (hold, release)
  5                  : insert coin     1          : start game
  Z / / / Space      : nudge left / right / centre (three quick nudges = TILT)

Rules
  - F-A-N-N-Y targets light LE CERCLE; ball in the lit Cercle = TRIPLETTE MULTIBALL (3 balls).
  - During multiball every ramp is a JACKPOT (20,000, +5,000 each time); three jackpots light the
    SUPER JACKPOT at the Cercle.
  - T-O-U-R top lanes (lane change with the flippers): bonus x2 ... x5, then EXTRA BALL at the Cercle.
  - BOUCHON lights CARREAU on TIRER for 20 s (10,000); POINTER (or TRIPLETTE) then BOUCHON = BIBERON.
  - Ramp: World Tour stops (Marseille, Paris, London, New York, Tokyo, Rio, Sydney);
    7 stops = GRAND CHELEM + EXTRA BALL.
  - Ball save at start of ball and of multiball, free game (replay) at 150,000 / 300,000 / 500,000
    and at the high score, MATCH at game over, TILT with two warnings.

Credits
  Game design, artwork, sounds and code: Arducible (guiraudjb). Table generated from the original
  web game geometry with vpin / vpxtool (Rust). Background videos: the Arducible DIY petanque game.


FRANCAIS
--------
Configuration
  - Visual Pinball X 10.8 ou plus (essayee sur VPX 10.8.0 standalone, Linux / Batocera, vue bureau).
  - AUCUNE ROM, ni VPinMAME, ni controller.vbs : jeu original, toutes les regles sont dans le script.
  - Sons, musiques, plateau et fond anime de la vue bureau sont dans le .vpx.
  - Pas encore de .directb2s : la vue bureau montre le fronton et l'afficheur a points a droite.

Installation
  Copier "Fanny Pinball (Arducible 2026) v1.0.vpx" dans le dossier des tables et la lancer.

Touches (celles de VPX)
  Maj gauche / droite : palettes       Entree : lanceur (tenir, lacher)
  5                   : credit         1      : depart
  Z / / / Espace      : coups de caisse (trois coups rapproches = TILT)

Regles
  - Les cibles F-A-N-N-Y allument LE CERCLE ; bille dans le Cercle allume = TRIPLETTE MULTIBALL (3 billes).
  - En multiball, chaque rampe = JACKPOT (20 000, +5 000 a chaque fois) ; trois jackpots allument le
    SUPER JACKPOT au Cercle.
  - Couloirs T-O-U-R (decales par les palettes) : bonus x2 ... x5, puis EXTRA BALL au Cercle.
  - BOUCHON allume CARREAU sur TIRER pendant 20 s (10 000) ; POINTER (ou TRIPLETTE) puis BOUCHON = BIBERON.
  - Rampe : escales du World Tour ; 7 escales = GRAND CHELEM + EXTRA BALL.
  - Sauvetage de bille, partie gratuite a 150 000 / 300 000 / 500 000 et au record, MATCH, TILT.
