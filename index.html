FannyPétanque World Tour

Commandes
  • Maj gauche / ← : flipper gauche
  • Maj droite / → : flipper droit
  • ↓ : lanceur (maintenir pour tirer, relâcher pour lancer : plus on tire, plus il frappe fort)
  • Entrée : nouvelle partie · A : autoplay (le robot joue seul) · P : pause · M : son · V : vue 2D / 3D / 3D légère · K : caméra (en « tour » : glisser pour tourner, molette pour zoomer)
  • Caméra « machine » : glisser pour choisir l'angle, molette ou pincer pour zoomer, puis L ou « Verrouiller la vue » pour jouer avec la souris ou au doigt
  • H ou « Habillage » (caméras machine et tour) : change le décor de la caisse
  • T ou « Fronton » (caméras machine et tour) : rabat le fronton sur la caisse pour le transport, ou le relève
  • Tactile : moitié gauche / droite du plateau, couloir de droite pour lancer

Avant le lancement, les flippers déplacent le couloir allumé (tir parfait).

F‑A‑N‑N‑Y ouvre le Cercle · 2 boules placées = multiball Triplette · 2 rampes = escale suivante · couloirs T‑O‑U‑R = bonus ×.
